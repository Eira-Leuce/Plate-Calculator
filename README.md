# Plate-Calculator
Программа по расчету изгиба прямоугольных пластин
**Дипломный проект**
Plate Calculator - десктопное приложение для численного моделирования изгиба тонких прямоугольных пластин на основе теории Кирхгофа (уравнение Софи-Жермен - Лагранжа). 

Программа позволяет проводить расчеты напряженно-деформированного состояния пластины, строить поля распределения прогибов, моментов и напряжений, а также исследовать сходимость и сравнивать различные численные методы.
## Основные возможности
**Два численных метода**:
Метод конечных разностей (МКР).
Метод дифференциальных квадратур (МДК / DQM) с возможностью выбора равномерной сетки или узлов Чебышева-Гаусса-Лобатто.

**Граничные условия**: шарнирное опирание по контуру и жесткая заделка.

**Материалы и геометрия**: встроенный шаблон стандартной стальной пластины (6х3 м) + возможность задать любые пользовательские параметры (размеры, модуль Юнга, коэф. Пуассона, нагрузку).

**Рассчитываемые параметры**:
Прогибы
Изгибающие и крутящие моменты
Поперечные силы
Напряжения

**Сравнение**: модуль сравнения сходимости методов с аналитическим/приближенным решением (по методу Бубнова-Галеркина - расчеты этого метода были выполнены в Matlab).

**Экспорт отчетов**: автоматическая генерация отчета в формате `.docx` с результатами и графиками.
## Стек
**Язык**: Python.

**GUI**: Tkinter

**Математика и матрицы**: NumPy, SciPy

**Визуализация**: Matplotlib

**Экспорт данных**: python-docx
## Структура проекта
```
PlateCalculator/
│
├── app/
│   ├── calculations/    # Математические солверы (МКР, DQM, сравнение методов)
│   ├── export/          # Логика экспорта графиков и данных
│   ├── gui/             # Графический интерфейс пользователя (Tkinter)
│   ├── postprocessing/  # Отрисовка графиков (Matplotlib)
│   └── utils/           # Вспомогательные функции
│
├── results/             # Папка для сохранения сгенерированных отчетов
├── main.py              # Точка входа в программу
├── requirements.txt     # Зависимости проекта
└── README.md            # Описание проекта
```
